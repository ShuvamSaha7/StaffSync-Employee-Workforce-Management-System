# StaffSync – Employee & Workforce Management System

StaffSync is a web-based Employee and Workforce Management System built using Java and Spring Boot for managing employees, departments, projects, attendance, payroll, and leaves.

## 🚀 Features

- Employee CRUD & Search
- Department Management
- Project Management
- Employee–Department–Project Mapping
- Attendance Management
- Payroll Management
- Leave Management
- HR Dashboard & Statistics
- Login & Logout
- BCrypt Password Encryption
- Form Validation
- Global Exception Handling
- Responsive Thymeleaf UI
